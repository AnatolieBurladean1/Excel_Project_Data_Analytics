# Excel Projects — Data Jobs Salary Analysis

Two Excel projects on real-world **2023 data job postings**, plus my practice files for each Excel topic.

| Project | Excel skills | Question answered |
|---|---|---|
| [Project 1 – Salary Dashboard](Project_1-Dashboard/) | Array formulas (MEDIAN/IF, FILTER), data validation, map and bar charts | What's the median salary for a data job by title, country and schedule type? |
| [Project 2 – Job Market Analysis](Project_2-Analysis/) | Power Query, Power Pivot, DAX, Pivot Tables and Pivot Charts | Do more skills mean higher pay? How do salaries differ by region? Which skills pay best? |

**Key findings**
- Salary rises with the number of skills a job asks for; Senior Data Engineer and Data Scientist roles pay the most.
- SQL and Python are the most requested skills across data jobs; cloud tools (AWS, Azure) are growing.
